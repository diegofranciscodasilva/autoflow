VERSAO DO PROJETO AUTOFLOW

Versao atual: 1.0.0
Data desta revisao: 2026-11-20

1. HISTORICO DA CRIACAO
O projeto foi criado como uma aplicacao de portifolio para demonstrar integracao entre frontend web e backend Python.

A interface foi implementada com HTML, CSS e JavaScript sem frameworks frontend.
O backend foi implementado em Flask para receber uploads e responder com JSON ou downloads.
As planilhas foram integradas com pandas e openpyxl.
A organizacao de arquivos foi implementada com zipfile e classificacao por extensao.
Os arquivos sao tratados em memoria, sem banco de dados e sem persistencia local dos uploads.
